# 📌 What is PrepAI?

Most candidates prepare using passive resources like videos and flashcards. PrepAI provides realistic AI-powered interview practice tailored to actual job descriptions.

You paste a job description from LinkedIn, Naukri, or any hiring platform. Gemini AI reads the JD and generates 5 technical interview questions specific to that exact role, company, and tech stack.

You answer each question and receive:
- AI-generated scoring
- Detailed feedback
- Strength analysis
- Improvement suggestions

Every session is saved so users can track progress over time.

# 🛠️ Tech Stack

## Frontend
- **React.js (Vite)** — component-based frontend architecture
- **CSS** — fully custom responsive UI
- **Vercel** — frontend deployment

## Backend
- **Python Flask** — REST API backend
- **SQLite** — lightweight relational database
- **Google Gemini 2.5 Flash API** — AI question generation and evaluation
- **Gunicorn** — production WSGI server
- **Render** — backend deployment

# 🏗️ Architecture

```text
User → React Frontend (Vercel)
      ↓ HTTP API Calls
Flask Backend (Render)
      ↓
Gemini AI API
      ↓
SQLite Database
```

# ⚙️ How It Works

## Step 1
Paste a job description from LinkedIn, Naukri, or any platform.

## Step 2
Gemini AI analyzes the job description and generates 5 targeted technical interview questions.

## Step 3
Users answer the questions and instantly receive:
- AI scoring
- Feedback
- Improvement suggestions

All interview sessions are stored for future review.

# 📡 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/health` | Server health check |
| POST | `/generate-questions` | Generate interview questions from JD |
| POST | `/evaluate-answer` | Evaluate answer and return score + feedback |
| GET | `/get-sessions` | Retrieve all interview sessions |
| GET | `/get-session/<id>` | Retrieve a complete session |

# 🧠 Engineering Decisions

## Why Flask instead of Node.js/Express?

Python provides a stronger ecosystem for AI integration and prompt engineering. Since the core feature relies on Gemini AI, Flask simplified backend development and integration.

---

## Why SQLite instead of PostgreSQL?

SQLite is lightweight, fast, and requires zero configuration, making it suitable for a solo full-stack project and rapid deployment.

For large-scale production usage, PostgreSQL with connection pooling would be more suitable.

---

## Why store sessions in the backend?

Server-side session storage allows:
- Persistent history tracking
- Cross-device access
- Better separation of concerns between frontend and backend

---

## How does AI evaluation work?

The backend sends:
- Original question
- User answer
- Structured evaluation instructions

to Gemini AI.

The AI returns structured JSON containing:
- Score
- Feedback
- Strengths
- Areas for improvement

The response is parsed and stored in SQLite.
